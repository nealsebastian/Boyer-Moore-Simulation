Algorithmic Behavior Summary:

📖 Theoretical Framework (Unit–4 String Matching)

1. The Sublinear Paradigm & Right-to-Left Scanning

In classical string matching, algorithms inspect pattern characters from left to right ($j = 0 \to m-1$). The Boyer–Moore algorithm fundamentally reverses this convention by comparing characters from right to left ($j = m-1 \to 0$), while shifting the pattern window from left to right across the text ($s \ge 0$).

By failing early on the trailing characters of the pattern window, the algorithm gains maximum information about whether the pattern could possibly occur in the current window.

2. The Bad Character Heuristic

Let $L(c)$ be the Last Occurrence Function, defined as the highest index in the pattern $P$ where character $c$ appears (or $-1$ if absent):

L(c) = max { k | P[k] == c }   (or -1 if c ∉ P)

When a mismatch occurs at pattern index $j$ against text character $T[s + j]$:

Shift_BC = max(1, j - L(T[s + j]))

If $T[s + j]$ does not appear in $P$ at all ($L(c) = -1$) and mismatch occurred at $j = m-1$, the pattern shifts by a full $m$ positions in a single step!

3. The Strong Good Suffix Heuristic

When a mismatch occurs at $P[j]$, the suffix $t = P[j+1 \dots m-1]$ has already matched the text. The Good Suffix rule determines the shift via two conditions:

  • Case 1 (Strong Suffix Rule): If $t$ appears elsewhere in $P$ preceded by a character different from $P[j]$, shift $P$ to align that occurrence with $T$.
  • Case 2 (Prefix Border Rule): If $t$ does not appear elsewhere, find the longest proper prefix of $P$ that matches a proper suffix of $t$, and shift to align them.
  • Case 3: If neither condition holds, shift the pattern completely past the matched suffix by $m$.

Design, Simulation, and Empirical Analysis of the Boyer–Moore String Matching Algorithm

Course: Design and Analysis of Algorithms (DAA) | Unit–4 String Matching

1. Introduction & Theoretical Context

Exact string matching represents one of the core problems in computational algorithms. Given a text string $T$ of length $n$ and a pattern $P$ of length $m$ ($m \le n$), the objective is to determine all alignment offsets $s$ where $P$ appears verbatim in $T$. While brute-force matching inspects every alignment requiring $O(n \cdot m)$ worst-case time, and Knuth-Morris-Pratt achieves linear $\Theta(n)$ time by eliminating text backtracking, the Boyer–Moore algorithm is renowned for its sublinear average-case runtime ($\approx O(n/m)$).

2. The Dual Heuristic Principle

Boyer–Moore achieves its extraordinary skipping power by scanning characters from right to left ($j = m-1 \dots 0$) and computing two shift recommendations upon mismatch:

  • Bad Character Rule ($\Delta_{BC}$): Uses the Last Occurrence Table $L(c)$ to shift the pattern so that the mismatched text character aligns with its rightmost appearance in $P$: $\Delta_{BC} = \max(1, j - L(T[s + j]))$.
  • Good Suffix Rule ($\Delta_{GS}$): Uses the matched suffix $P[j+1 \dots m-1]$ to find either an internal identical copy preceded by a distinct character (Strong Suffix) or the longest prefix matching a suffix of the matched portion (Prefix Border).

The final shift applied is strictly the maximum: $s_{next} = s + \max(\Delta_{BC}, \Delta_{GS})$, guaranteeing both safety (no missed matches) and maximal progress.

3. Experimental Validation & Results

Through rigorous empirical trials on randomized and benchmark datasets, the following observations were proven:

  1. Sublinear Pattern Scaling: As $m$ grew from 4 to 50, Boyer–Moore comparisons dropped from 2,200.7 down to 425.5 (~95% fewer checks than Naive and KMP).
  2. Alphabet Size Impact: On large alphabets such as English ($|\Sigma|=26$) and ASCII ($|\Sigma|=62$), Bad Character shifts achieved full length $m$, requiring only 553 comparisons compared to 5,000 for KMP.
  3. Wall-Clock Execution: Across texts from 2,000 to 80,000 characters, Boyer–Moore maintained a sustained 3.1× to 3.7× speed advantage over KMP.

4. Industrial Applications

Because of its sublinear character skipping, Boyer–Moore and its variants (such as Boyer-Moore-Horspool and Commentz-Walter) serve as the default search engine in GNU grep, biological sequence alignment tools (BLAST), and packet payload filtering engines in Network Intrusion Detection Systems (Snort, Suricata).
